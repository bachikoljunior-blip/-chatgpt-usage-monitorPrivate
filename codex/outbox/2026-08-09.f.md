## 見つかった不満（3件まで）

- LiteLLMの価格表で15モデルの料金が欠落し、ダッシュボードが `$0.00` または `-` になって原価追跡不能 / [GitHub Issue #22646](https://github.com/BerriAI/litellm/issues/22646) / 2026-03-03 / このIssue内で15モデル。独立した同種報告は下記を含め計3件確認
- カスタムモデルの価格を設定しても実際の原価計算に反映されず、支出がすべて `$0.00` になる / [GitHub Issue #11975](https://github.com/BerriAI/litellm/issues/11975) / 2025-06-23。2026-03-11、2026-05-19にも別経路で同種問題が再言及 / 同Issueと後続言及を合わせ3件
- キャッシュ読み書きなど料金次元がプロバイダーごとに異なり、単純な入力・出力単価表では正しく計算できない / [GitHub Issue #27191](https://github.com/BerriAI/litellm/issues/27191) / 2026年5月ごろ / Issue中に「数千リクエスト後もキャッシュ使用量が0」となる具体例1件。別途、Portkeyもキャッシュ、画像、動画、検索など20種類以上の料金次元を列挙

## 競合

- Portkey Models / 200社超で利用、毎日4000億トークンの原価計算に使用、2,000超モデル・40超プロバイダー、GitHub 123 stars / 評価制度なし / 最終更新日は未確認 / 無料・認証不要API、正規化済み料金、キャッシュ・画像・動画・検索料金まで提供しており、中心的な不満をほぼ解決済み。[リポジトリと利用規模](https://github.com/Portkey-AI/models)
- LiteLLM `model_prices_and_context_window.json` / リポジトリは10.4k forks、Issue 1.6k件 / 評価制度なし / 2026-03-03時点のlatest mainでも15モデル欠落を確認 / 広く利用される無料の標準価格表だが、欠落・更新遅延が実在する。[欠落の証拠](https://github.com/BerriAI/litellm/issues/22646)
- OpenRouter Models API / 導入数・評価は未確認 / 現行ドキュメントを2026-08-09確認 / モデルID、コンテキスト長、入出力単価などをAPIで返す。ただしOpenRouter上のモデルが対象で、全プロバイダーの公式直販料金を網羅するものではない。[公式API](https://openrouter.ai/docs/api/api-reference/models/list-all-models-and-their-properties)

作るべきものを限定するなら、単なる「最新LLM料金JSON」ではありません。公式ページの変更履歴、取得時刻、出典、旧価格との差分、破壊的変更通知を備えた監査可能な料金変更フィードです。ただしPortkeyの無料APIより明確に優れる必要があり、有料需要は未検証です。

## 有料化の実例

- LLM料金の正規化データ／差分フィードそのものを、無料版から有料購読へ転換している実例は確認できなかった。確認できた主要例はPortkeyの無料・認証不要APIであり、Portkey本体の有料ゲートウェイとは別物
- 隣接するデータAPIではCanopy APIが無料枠から従量課金へ転換した実例あり。ただし当時の具体的単価は確認できなかった。[有料転換の報告](https://www.indiehackers.com/product/canopy-api/first-paying-customer--NNY8HNkHoJRkJyvbgZM)

## 判定

この候補は、現状のままでは見積りに見合わない。実在する不満は強いが、2,000超モデルを扱い200社超で使われる無料APIがすでにあり、「更新された正規化フィード」だけでは購入理由にならない。

初円の近い実例はCanopy APIで、公開説明が2023-01-24、最初のorganic有料転換が2023-02-05なので約12日。ただし公開時にIndie Hackersで利用者募集と割引提示をしており、公開前の読者・顧客リストの有無は未確認である。売上0・流入経路0から同じ速度を再現できる証拠にはならない。
