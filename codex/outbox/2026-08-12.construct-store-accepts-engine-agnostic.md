# Construct Asset Store はエンジン非依存の HTML/JS 商品を受け付けるか

調査日: 2026-08-12  
task_id: `2026-08-12.construct-store-accepts-engine-agnostic`

## 判定

1. **素の HTML / CSS / JavaScript 一式を出品できるか: 確認できない**
2. **Construct 非依存の商品が実際に売れている実例: ある**
3. **ただし、その実例は Windows 向けツールであり、素の HTML/JS ソース商品ではない**

公開中の公式ストアには Construct のプロジェクト形式を前提にしないカテゴリがあり、実際に `.c3p` や `.c3addon` を含まない Windows 用ツールが販売されています。そのため、**全商品に Construct 専用ファイルが必須ということはありません**。

一方で、公開されている現行の規約・FAQ・出品案内には、素の HTML / CSS / JavaScript のソース一式を商品として受け付ける、という明文がありません。検索で見つかった HTML5 ゲーム商品は、確認した範囲では Construct の `.c3p` または `.capx` も同梱していました。したがって、**Windows ツールが通ることから HTML/JS ソースも通る、とまでは断定できません**。

## 出品カテゴリ

現行ストアの公式ナビゲーションに表示されているカテゴリ名は次のとおりです。

- Addons
- Animations
- EBooks
- Fonts
- Games
- Graphics
- Sounds
- Templates
- Themes
- Tilemaps
- Tools

このうち、少なくとも **EBooks、Fonts、Games、Graphics、Sounds、Tilemaps、Tools** は、カテゴリ名自体には Construct 3 のプロジェクト形式を要求していません。特に Tools では Windows 用実行ファイルの販売実例を確認できました。

ただし、**カテゴリ名だけでは素の HTML/JS ソースを Tools、Games、Templates のどれで受理するかは確認できません**。

根拠:
- [Game Developer Asset Store](https://www.construct.net/en/game-assets) の「Game Assets」ナビゲーション
- 公式規約は出品物を “assets or software” と表現しており、Construct 専用形式だけに限定していません。ただし HTML/JS を明示的に許可しているわけでもありません。
  - [Store Terms and Conditions](https://www.construct.net/en/game-assets/terms-and-conditions)

## 必須ファイル形式

### 公開情報から確認できたこと

- 公式ブログには、1リリースにつき **最大10ファイル、各200MB** とあります。
- 公開中の Array Editor 商品では、配布物が `ArrayEditorWin64.zip` で、その中に `ArrayEditor.exe` などが入っています。
- この実例には、公開ページ上で `.c3p` または `.c3addon` は表示されていません。
- したがって、**ストア全体で `.c3p` や `.c3addon` が必須ではありません**。
- ZIP 形式の商品が現在公開され、購入可能であることは確認できました。

### 公開情報から確認できなかったこと

- 出品フォームで選べる拡張子の完全な一覧
- 素の HTML / CSS / JavaScript をまとめた ZIP が審査対象として受理されるか
- Games または Templates カテゴリで `.c3p` なしの商品を受け付けるか
- HTML/JS ソース商品の必須ドキュメント、プレビュー、サポート条件

## Construct で動かない商品の販売実例

### Array Editor

URL: https://www.construct.net/en/game-assets/tools/array-editor-120

確認できた数字と内容:

- カテゴリ: **Tools**
- 価格: **$5 USD**
- Total sales: **100+**
- レビュー数: **1**
- 評価: **5**
- Compatibility: **Windows**
- 配布物: **ArrayEditorWin64.zip**
- ZIP 内の主要ファイル: **ArrayEditor.exe**
- Construct プロジェクトファイル: 公開ページ上では表示なし

これは Construct の `.c3p` を開く商品ではなく、Windows 上で動く独立したツールです。JSON の import / export を行うため Construct と組み合わせる用途はありますが、商品ページの互換性表示は Construct ではなく **Windows** です。

この実例から分かること:

- Construct 非依存の実行形式でも出品・販売実績を作れる
- ZIP と EXE の組み合わせが少なくとも1件公開されている
- Construct 専用プロジェクト形式はストア全商品共通の必須条件ではない

この実例からは分からないこと:

- HTML / CSS / JavaScript のソース一式も同じ審査基準で通るか
- Construct と組み合わせる用途がない完全な汎用 Web 商品でも通るか

## 検索で確認した HTML5 商品

HTML5 ファイルを含む商品はいくつも見つかりましたが、確認した商品は Construct のソースも同梱していました。

例:

- [Space Survivor](https://www.construct.net/en/game-assets/games/with-source/space-survivor-1988)
  - `.c3p`、`.capx`、HTML5 を同梱
- [Circle Runner](https://www.construct.net/en/game-assets/games/with-source/circle-runner-3179)
  - HTML、CSS、JavaScript の書き出し一式に加えて `.c3p` を同梱
- [Jumping Frog](https://www.construct.net/en/game-assets/games/with-source/jumping-frog-4255)
  - HTML5 ファイルと Construct 3 のソースを同梱

したがって、**素の HTML/JS だけで売れている実例は、今回の検索では見つからなかった**とします。

## 出品審査の日数

**現行の公式公開ページでは確認できませんでした。**

2015年の公式フォーラムには Construct Team の回答として「通常は最大2営業日」という記載が検索結果にありました。しかし、その後2021年に新しい Asset Store が公開されているため、これを2026年現在の保証としては扱いません。

参考にとどめる旧情報:
- [Scirra store - approve time?](https://www.construct.net/en/forum/scirra-website/website-issues-and-feedback-35/scirra-store-approve-time-97268)

## $20 を払う前に分かっていない残りの条件

- 素の HTML / CSS / JavaScript 一式を、Construct の `.c3p` なしで受理するか
- その商品を **Games、Templates、Tools** のどこへ出すべきか
- 出品フォームの現行ファイル拡張子制限
- HTML/JS ソース商品の審査基準
- 現行の標準審査日数
- Construct と無関係な汎用 Web 商品でも受理するか
- Royalty Free ライセンスのどの商品種別を HTML/JS ソースに適用するか
- 審査前にサポートへ商品サンプルを送り、書面で可否確認できるか

### $20 を払う前の安全な判断

公開情報だけで支払い判断をするなら、**まだ払わない**のが妥当です。

支払う前に Scirra へ、次の1点を商品構成まで書いて確認する必要があります。

- “Can I sell a ZIP containing only original HTML, CSS and JavaScript source files, with no .c3p, .capx or .c3addon file?”

これはストアに非Construct商品が存在するかではなく、**今回の商品形式そのものが受理されるか**を聞く質問です。
