## 見つかった不満（3件まで）

- ハンドメイド商品の合計生産能力を週20個に制限したいが、在庫を毎週手作業で補充するのは避けたい / [WordPress.org サポート](https://wordpress.org/support/topic/limited-stock-per-week-shared-accross-all-products-handmade-products/) / 約2年前 / 同種の独立した投稿を計3件確認
- 週27件に達したら受注を止め、翌週に自動リセットしたい / [Reddit / r/Wordpress](https://www.reddit.com/r/Wordpress/comments/j5uo0b) / 2020-10-05 / 同種の独立した投稿を計3件確認
- 週または月の受注総数を制限し、上限到達後は次の期間まで注文を無効化したい / [Reddit / r/woocommerce](https://www.reddit.com/r/woocommerce/comments/f8cu53) / 2020-02-24 / 同種の独立した投稿を計3件確認

WooCommerce標準では商品ごとの在庫管理はできても、「複数商品で共有する週次の生産能力枠」は標準機能ではないことを、最初のWordPress.org投稿に対する公式回答でも確認した。

## 競合

- [Order Limit for WooCommerce（無料版）](https://wordpress.org/plugins/wc-order-limit-lite/) / 800+有効インストール / 4.2・13レビュー / 2か月前更新 / 日・週・月・年単位のリセットは無料版にあり、ストア全体の週次受注上限はProで解決。今回の中心的な不満をほぼそのまま解決している
- [Order Limit for WooCommerce（Pro）](https://woocommerce.com/products/order-limit/) / 100+有効インストール / 評価は商品ページで未表示 / 最終更新日は未表示、最新版5.5.5 / ストア全体の注文数・注文額を週単位で制限し、自動リセットできるため、完全な直接競合
- [Auto Product Restock for Woo](https://es.wordpress.org/plugins/auto-product-restock-for-woo/) / 20+有効インストール / 5.0・1レビュー / 約1年前更新 / 商品在庫の週次・月次自動補充を無料で実行できる。ただし複数商品を横断した単一の生産能力枠にはならない
- [WPC Shared Stock](https://en-gb.wordpress.org/plugins/wpc-shared-stock/) / 50+有効インストール / レビューなし / 7日前更新 / 複数商品・バリエーションの在庫を共通枠にできる。週次リセットは確認できないが、共有在庫部分は既に解決している

作るとすれば「複数商品を横断する週次生産枠＋売り切れ後に最短の将来週へ受注を割り当てる機能」だが、前半は既存製品で解決済みであり、後半だけでは短期販売を裏付ける需要件数が足りない。

## 有料化の実例

- [Order Limit for WooCommerce](https://woocommerce.com/products/order-limit/) — 年額49ドル、2年78.40ドル。年次サブスクリプション方式。無料版の管理画面・WordPress.orgページからProへ誘導し、ストア全体の期間別上限などを有料化している
- [Independent Analytics Pro](https://independentwp.com/pricing/) — 1サイト年額49ドル、3サイト79ドル、無制限199ドル。ライセンスキー付き年次サブスクリプションで、買い切りプランも選択可能。無料版からProへ誘導する実在例
- 同製品の公開記録では、Pro公開当日に最初の販売が発生したが、既存利用者へのメールと告知記事を使ったローンチだった。[31日間の販売記録](https://www.indiehackers.com/product/independent-analytics/31-days-after-launch-2-400-in-sales--NFiAWm85UdSHO3dyDZL)
- 一方、別のWordPressプラグイン Gato GraphQL は最初の販売まで約2.5か月を要している。[開発者の記録](https://www.indiehackers.com/post/i-got-my-first-sale-this-is-what-worked-what-failed-and-what-failed-miserably-833759a3ca)
- WordPress.orgディレクトリへ新規無料版を公開し、既存顧客・メーリングリストなしで最初の販売に至った日数が分かる実例は確認できなかった。

## 判定

この候補全体の有料化モデルは実在するが、提示された初円までの日数には見合わない。確認できた即日販売例は既存利用者と告知経路を持つ製品であり、現在の「売上0・流入経路なし」と条件が異なる。

今回確認した週次生産枠は、800+インストールの無料版と年額49ドルの直接競合が既に解決している。新規ディレクトリ流入だけで期限内に初円へ到達できる実例も確認できないため、この具体案は作らない方がよい。
