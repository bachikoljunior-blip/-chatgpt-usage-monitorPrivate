## 今回やること（**有料アセットを、ページを作らずに今日出せる場所を探す**）

売るものは `state/gumroad.json` と `assets/listing/gumroad.ja.json` にあります。
USD 25 の有料 HTML/CSS/JS キットで、買い手は自分で idle/clicker ゲームやサイトを
公開する開発者です。

**venue はいくつでも構いません。0件でも構いません。**
数を揃えることに価値はありません。**1件でも条件を全部満たすものが実在すれば、
そのほうが5件の当てずっぽうより価値があります。**

### 満たしていなければ落とす条件（**1つでも欠けたら venue として数えない**）

1. **有料商品の宣伝が規約上ゆるされる。** 「無料なら可」は該当しません。
   **規約の原文引用が取れること。** 引用が無いものは落としてください
2. **そのプラットフォーム上に商品ページやプロジェクトを作る必要が無い。**
   外部リンク（Gumroad）を直接貼れること。ここが .o で itch.io が止まった理由です
3. **投稿資格が数値で確認できる、または「特に無い」と明記されている。**
   確認できないものは落としてください。**推測で埋めないこと。**
   .o で GameDev.net を落としたのはこの条件です
4. **その枠に、直近の実投稿が日付つきで1件ある。** 休止中の板を掴まないためです

### 各1件について答えること

1. **名前と、実際に開いた URL**
2. **有料宣伝を許す規約の該当箇所を、原文のまま引用**（要約しない）
3. **投稿資格。数値で書いてあるものは数値のまま。**「特に無い」ならそう書く
4. **外部リンクを直接貼れることの根拠。** 規約の引用か、外部リンクを含む実投稿の URL
5. **その枠の URL と、直近の実投稿の日付**

### やってはいけないこと

- **投稿しないでください。アカウントも作らないでください。** 調査だけです
- **規約を要約しないでください。** こちらが判断します。引用が要ります
- **開いていない URL を書かないこと**
- **`no_standing_where_buyers_gather.venue_survey` に既にある3件を再提出しないこと**

### 出力の形

- venue ごとに1節。見出しはその venue の名前
- 各節に上の1〜5を、番号のまま
- 満たせなかった条件は、その番号の下に「できない」と理由を1行

最後に `## 判定` を置き、次に答えてください。

- **実際に開いた URL はいくつか**（数字で）
- **上の4条件を全部満たした venue はいくつか**（数字で。**0 は正しい答えです**）
- **0件だった場合、その理由は「規約が有料を許さない」「ページ作成が要る」
  「資格が確認できない」のどれが一番多かったか。**1つ選んでください
- **こちらの詰まり（添付の `state/eta.json` の候補一覧）に対して、
  あなたが「文章や調査ではないもの」を現物で出せるか。**
