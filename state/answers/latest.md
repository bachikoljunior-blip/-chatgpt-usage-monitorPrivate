## 1位：WordPressプラグイン→Pro版

狙うのは汎用AIプラグインではなく、「すでに収益を持つサイト運営者が検索する、小さく切実な問題」です。販売目標は年額14,800円の商品を月14件、または月額2,980円を67契約です。

最初の7日間：

- 1日目：WordPress公式ディレクトリから、既存上位プラグインの低評価レビューとサポート投稿を収集。AIで「頻出する未解決問題」「外部API不要」「読み取り中心」「30秒で価値が分かる」に絞る。
- 1日目：候補を3つ採点する。基準は検索需要、競合の弱さ、障害時の損害、サポート負担、ローカル処理可能性。最高点の1件だけ作る。
- 2日目：無料版を実装。機能は「検査・少量プレビュー・問題件数表示」までに限定する。
- 3日目：Pro版を実装。「一括修正、CSV出力、定期実行、複数サイト用ライセンス」のうち保守不要なものだけ載せる。
- 3日目：価格を年額14,800円、買い切り29,800円程度で開始。決済Webhookから署名済みライセンスファイルを自動発行する。
- 4日目：英語を主言語、日本語を追加して商品ページ、FAQ、動画GIF、比較表を生成。問い合わせの代わりに自己診断ログを表示させる。
- 5日目：無料版をWordPressへ申請。ここが最大1回の人手作業。審査修正が必要になる可能性は要確認。
- 6日目：同じ問題名で無料診断ページを公開し、プラグインページとPro購入ページを相互接続する。
- 7日目：CIで週次集計を開始。閲覧→インストール→Proクリック→購入だけを見て、購入ゼロなら機能追加ではなく商品名・説明・価格を自動テストする。

避けるべき題材は、セキュリティ、決済、バックアップ、メール配信など、障害対応が不可避なものです。

## 2位：VS Code拡張→有料版

販売目標は買い切り4,980円を月41件、または年額9,800円を月21件。AI呼び出しを必須にせず、ローカル処理だけでも価値が残る設計にします。

最初の7日間：

- 1日目：Marketplaceのレビュー、GitHubの公開Issue、検索候補から「毎週繰り返す面倒」を抽出する。秘密情報探索、ログ整形、設定移行、巨大JSON比較、テストデータ生成などを候補にする。
- 1日目：競合拡張を10件以内で比較し、「競合にない一括操作」を1つ選ぶ。単なるAIチャット拡張は除外する。
- 2日目：コマンド1個で結果が出る無料版を作る。インストール後30秒以内に価値を確認できるサンプルを同梱する。
- 3日目：Pro版にフォルダ一括処理、CI用CLI、保存プリセット、レポート出力を追加する。サーバー依存は持たせない。
- 4日目：英語のMarketplaceページを主にし、日本語説明を追加。タイトルには問題名と処理対象を明記する。
- 4日目：ライセンスは決済後に署名ファイルを自動発行。拡張側は公開鍵で検証し、認証サーバーを不要にする。
- 5日目：Marketplaceへ公開し、GitHub Actionsでタグ作成から公開まで自動化する。
- 6日目：同じエンジンを無料CLIとしてnpmにも公開し、CLI検索から拡張とPro版へ送客する。
- 7日目：インストール数、初回コマンド実行、Pro画面表示、購入だけを集計。利用されなければ題材を捨て、同じ販売・ライセンス基盤で次の拡張を出す。

最短路の核心は、最初の製品を育て続けることではなく、共通の決済・ライセンス・計測基盤を一度作り、7〜10日単位で小型商品を追加することです。目安は90日でWordPress 3本、VS Code 4本。その中の上位1〜2本へだけ自動改善を集中させます。
