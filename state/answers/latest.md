結論として、露出が完全に止められているというより、**少人数への初期配信はされているが、反応が弱く拡大しない**状態に近いです。ただし、確定にはYouTube Studioの指標が必要です。

1. 登録率0.04%について

かなり低いです。YouTube公式は登録率の「正常値」を公表していませんが、外部ベンチマークではShortsの登録転換率は概ね **0.3〜0.8%**、1%超なら強い、とされています。ジャンルやチャンネル成熟度による差が大きいので、あくまで目安です。[参考ベンチマーク](https://retensis.com/blog/youtube-shorts-subscriber-conversion-rate-2026)

この目安なら2,435再生で7〜19人程度。実測1人＝0.041%は、下限0.3%の約7分の1です。開設1週間なので統計的な揺れは大きいものの、**「低め」ではなく、明確に弱い側**です。

主因として考えやすい順は、

- 動画から「今後もこのチャンネルを見る利益」が伝わらない
- 宣伝・テスター募集が視聴者側の負担として見える
- Android限定で対象を狭め、無料ブラウザ版という低摩擦の入口を隠していた
- ゲーム自体への興味より、単発の映像として消費されている

です。なお説明欄の修正は有効ですが、Shortsでは説明欄を開かない人も多いため、それだけで大幅改善する可能性は低いです。

2. 約200再生＋反応ほぼゼロから読めること

二択なら、**「多少おすすめに出ているが、初期視聴者に十分刺さらず、配信が拡大しない」寄り**です。

ただし再生数だけでは断定できません。2025年3月31日以降、Shortsの公開再生数は「再生開始・リプレイ」で加算され、最低視聴時間がありません。そのため、従来より再生数だけでは評価しにくくなっています。[YouTube公式](https://support.google.com/youtube/answer/10059070/get-started-with-youtube-shorts?hl=en-GB)

Studioで次の4点を確認すると分離できます。

- 「フィードに表示された回数」
- 「視聴を選択した割合／スワイプされた割合」
- エンゲージビュー
- 平均視聴時間・平均再生率

YouTube公式も、この組み合わせでShortsの露出と視聴選択を判断するよう案内しています。[YouTube公式の指標説明](https://support.google.com/youtube/answer/12942217)

見分け方は単純です。

- 表示回数自体が少ない → 対象視聴者を特定できていない可能性
- 表示されるがスワイプが多い → 冒頭・題材が弱い
- 視聴されるが維持率や反応が低い → 内容・結末が弱い
- 完走されるのに登録されない → 継続視聴の約束がない

コメント0件は、この再生規模なら単独では異常とまでは言えません。一方、いいね0〜2が継続することは、強い満足や共感が生まれていない兆候です。

3. ゲーム宣伝チャンネルの登録動機

「ゲームを宣伝する」ではなく、**登録すると次回も見たい連載が届く**状態を作ります。例えば、

- 「毎日1機能追加して、30日でゲームを完成させる」
- 視聴者コメントで次のアップグレードを決定
- 普通→異常にインフレする成長過程
- バグ、失敗、没仕様と、その修正結果
- 「10分放置するとどうなる？」など結果を見たくなる検証
- 次回に新ステージ・転生・ボスを公開する連続企画

募集CTAは「テスト参加してください」より、まず動画内で「無料ブラウザ版は今すぐ遊べます」。登録CTAは「毎日、次の進化を公開」のように、登録後の具体的利益を示す方が自然です。

4. 次に変える一点

**題材＝動画の企画設計**です。

サムネや投稿頻度より先に、単なるプレイ映像・機能紹介・募集から、**12〜20秒程度の“変化と結末がある連載”**へ変えるのが最優先です。実測でも13〜15秒が長尺より明確に強く、103秒級は現状のチャンネルには合っていません。

一例：

> 0秒：「この弱すぎるクリックを、15秒で壊します」  
> 1〜10秒：高速アップグレード  
> 11〜14秒：桁が爆発する結果  
> 最後：「次は転生を追加。無料版は説明欄」

要するに、現在の最大課題はサムネではなく、**視聴者にとっての見どころと、次も見る理由が弱いこと**です。15本・1週間ではチャンネル自体の失敗判定は早いですが、現行フォーマットをそのまま量産する段階ではありません。
