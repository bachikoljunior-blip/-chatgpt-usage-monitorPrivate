以下の日数はすべて、類似商品の成約率と現在の再生数から置いた**推測**です。「来る」は購入完了を指します。

| 順位 | 集客経路 | 日本向け | 英語圏向け | 失敗する主因 |

YouTubeは既に平均200再生×1日2本なので最優先です。通常動画とは別に売り込み動画を増やすより、既存2本のうち数本を制作キット実演へ差し替えます。

itch.ioは検索・Browse掲載があり、タグやDevlogも露出に使えます。ただし新規販売者は数営業日の審査対象になり得ます。[itch.io公式](https://itch.io/docs/creators/getting-indexed)

## 2. AIだけで実行できるもの

完全自動で可能なのは、**1位のYouTube**と**3位のGitHub Pages**です。  
itch.ioは今回、アカウント/API権限が与えられていないため実行できません。

### YouTube

1. 3つの例を各20〜35秒で録画する。
2. 冒頭3秒で「JSON 1枚を変えるだけで別ゲームになる」場面を見せる。
3. 日本語版と英語版を交互に作る。
4. タイトルを検索語中心にする。  
   日本語例：`HTML放置ゲームをJSONだけで作る｜ビルド不要・依存ゼロ`  
   英語例：`Build an Idle Clicker by Editing One JSON File`
5. 概要欄の1行目と固定コメント相当の文面にGumroad URLを置く。
6. YouTube APIで既存の1日2本枠へ投稿する。APIは動画とメタデータをアップロード可能です。[YouTube公式](https://developers.google.com/youtube/v3/docs/videos/insert)
7. 7日ごとに再生数とGumroad流入を見て、クリックされないタイトル・冒頭を交換する。

### GitHub Pages

1. 日本語・英語を切り替えられる商品紹介ページを作る。
2. 3種類の完成例を、その場で遊べるデモとして置く。
3. 「元JSON→変更箇所→完成結果」を並べる。
4. 設定生成ページを無料公開し、書き出し直前と結果画面に購入リンクを置く。
5. `idle game template`、`放置ゲーム テンプレート`など、用途別の説明ページを作る。
6. title、description、OG画像、構造化データ、サイトマップを設定する。
7. GitHubへ公開し、GitHub Pagesで配信する。Pagesは静的HTML/CSS/JavaScriptを直接公開できます。[GitHub公式](https://docs.github.com/en/pages)
8. 全YouTube動画から、Gumroadへ直接送る版とPagesの無料デモへ送る版を分けて反応を比較する。
