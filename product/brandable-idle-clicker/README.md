# ブランド差し替え型 放置クリッカー

設定ファイル **`brand.config.json` 1枚**を書き換えるだけで、
自分の店・商品・チャンネルの放置ゲームになります。

- **ビルド不要。** サーバーに置くだけで動きます
- **外部ライブラリなし。** 通信もしません（あなたが `cta.url` に入れたリンク以外）
- **スマホ前提。** 縦画面・片手・タップだけで遊べます
- **セーブは端末内。** サーバーもデータベースも要りません

---

## 0. いちばん早い作り方

`generator.html` をブラウザで開き、名前・色・増やすものを埋めて
「brand.config.json をダウンロード」を押してください。
出てきたファイルを、商品フォルダの `brand.config.json` に上書きすれば完成です。

値段と毎秒の量（遊びの速さ）は、釣り合いが取れた値をこちらで入れてあります。
入力した内容はどこにも送信されません。手で書きたい場合は次の節へ。

## 1. 5分で自分のものにする

### ① 名前と説明を変える

`brand.config.json` の `meta` を書き換えます。

```json
"meta": {
  "title": "まめや珈琲 焙煎クリッカー",
  "tagline": "煎って、淹れて、店を増やす。",
  "faviconEmoji": "☕"
}
```

### ② 色を変える

`theme` の色を変えます。`accent` がボタンの色、`accentText` はその上に載る文字の色です。
**この2つのコントラストだけは確認してください。** 他はそのままでも成立します。

```json
"theme": { "background": "#1a1410", "accent": "#c98a3c", "accentText": "#1a1008" }
```

### ③ 数える単位を変える

```json
"currency": { "name": "焙煎豆", "unit": "g", "emoji": "🫘" }
```

### ④ 増やすものを変える

`generators` が「買うと毎秒ふえる」もの、`upgrades` が「買うと倍率が上がる」ものです。
**`generators` は `baseCost` の安い順に並べてください。** 画面に出る順番になります。

```json
{ "id": "staff", "emoji": "🧑‍🍳", "name": "バリスタ", "desc": "淹れてくれる",
  "baseCost": 120, "baseRate": 1.6 }
```

- `baseCost` … 1個目の値段。2個目以降は 1.15 倍ずつ上がります
- `baseRate` … 1個あたり毎秒いくつ増えるか

### ⑤ 確かめる

```bash
python3 validate_config.py
```

問題があれば、どこをどう直せばよいか日本語で出ます。

### ⑥ 見る

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。
**ファイルをダブルクリックして開くと動きません**（ブラウザが設定ファイルの読み込みを禁止するため）。
上のコマンドで開いてください。

## 2. 公開する

フォルダの中身をそのまま置けば、どこでも動きます。

| 置き場所 | やり方 |
| --- | --- |
| 自社サイト | `/game/` などにフォルダごとアップロード |
| GitHub Pages | リポジトリに置いて Settings → Pages で公開 |
| Netlify / Cloudflare Pages | フォルダをドラッグ&ドロップ |

サーバー側の設定は要りません。PHP も Node も不要です。

---

## 3. 自分のサイトへ誘導する

遊んでいる途中でボタンを出せます。すぐ出すと押されないので、
`showAfterCurrency` である程度進んでから出るようにしてあります。

```json
"cta": {
  "enabled": true,
  "label": "お店の公式サイトへ",
  "url": "https://example.jp",
  "showAfterCurrency": 500
}
```

## 4. 設定の項目一覧

| 場所 | 意味 |
| --- | --- |
| `meta.title` | 題名。ブラウザのタブにも出ます |
| `meta.saveId` | 省略可。セーブの保存先を分けたいときだけ指定します |
| `theme.*` | 色（`#rrggbb`）と角の丸み |
| `currency.name` / `.unit` / `.emoji` | 数えるもの。「売上／円／💰」など |
| `tapTarget.baseValue` | 1タップで増える量 |
| `generators[]` | 買うと毎秒ふえるもの |
| `upgrades[].effect.type` | `tapMultiplier` / `rateMultiplier` / `offlineMultiplier` |
| `milestones[]` | 一定量に達したときに1回だけ出る文章 |
| `prestige` | リセットして永続ボーナスを得る仕組み。`enabled: false` で消せます |
| `offline` | 閉じている間の収入。`maxHours` で上限、`rateFactor` で割合 |
| `cta` | 誘導ボタン |
| `footer` | 一番下の表記 |

## 5. よくある詰まり

**ファイルを開いても「読み込み中…」のまま**
ダブルクリックで開いています。`python3 -m http.server 8000` で開いてください。

**「必須項目がありません」と出る**
`validate_config.py` を実行すると、足りない項目名が出ます。

**JSON が読めないと言われる**
末尾の余分なカンマ、閉じ忘れの括弧、全角のクォート（”）のどれかです。

**進行が消えた**
セーブは端末のブラウザに入ります。別の端末・シークレットウィンドウでは引き継がれません。

**題名を変えたら進行が消えた**
セーブの保存先は題名から決まります。題名を変えても進行を残したいときは
`meta.saveId` に固定の文字列を入れてください。

## 6. 中身

```
index.html            画面の骨組み
generator.html        設定ファイルを作るページ（開いて埋めるだけ）
assets/engine.js      ゲーム本体（編集不要）
assets/style.css      見た目（色は設定から入るので編集不要）
brand.config.json     ← ここだけ書き換えます
examples/             書き換え例3種（珈琲店・サロン・配信者）
validate_config.py    設定の検査
test_engine.py        ブラウザで動くかの自動検査（開発用）
```

`examples/` の中身を `brand.config.json` に上書きコピーすると、そのまま別ブランドになります。
